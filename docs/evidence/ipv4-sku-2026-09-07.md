# External IPv4 SKU observations

Observed on 2026-09-07 through the public Google Cloud SKU catalog in a browser.
This initial browser observation used no account-specific pricing API or billing data.

URL: https://cloud.google.com/skus?currency=USD&filter=C054-7F72-A02E

After opening the page, the filter contained `C054-7F72-A02E`. Pressing Enter
loaded the result. The browser accessibility tree displayed:

- Service: Compute Engine
- Service ID: 6F81-5844-456A
- SKU: External IP Charge on a Standard VM
- SKU ID: C054-7F72-A02E
- Region: global
- Free row: `0.00 USD (Free) per 1 hour, for 0 month to 1 month, per 1 month per account`
- Paid row: `0.005 USD per 1 hour, for 1 month and above, per 1 month per account`

This records the initial visible catalog text. At that stage, its month-to-hour
conversion had not been verified; the subsequent API observation below resolves
the current threshold as 720 hours.

The concurrently checked VPC pricing page says the free allowance is one hour
per month per account, then $0.005/hour for an in-use address on a standard VM:
https://cloud.google.com/vpc/network-pricing#ipaddress

## Subsequent pricing API observation, same date

Read-only GET requests to the public pricing endpoint and an authenticated
billing-account-specific pricing endpoint returned the same USD tiers:

- Public endpoint: `https://cloudbilling.googleapis.com/v1beta/skus/C054-7F72-A02E/price?currencyCode=USD`
- Account endpoint pattern: `/v1beta/billingAccounts/{billingAccount}/skus/C054-7F72-A02E/price?currencyCode=USD`
- `unitInfo`: unit `h`, quantity `1`
- First tier: `startAmount.value = 0`, price USD zero
- Second tier: `startAmount.value = 720`, `listPrice.nanos = 5000000` ($0.005/hour)
- Aggregation: `LEVEL_ACCOUNT`, `INTERVAL_MONTHLY`
- Account response: `contractPrice` matched the list price; `priceReason` was `default-price`

The observed price therefore grants 720 address-hours per account per month,
then charges $0.005 per address-hour. It is not a variable 720/744-hour allowance.
With one continuously used address, no other shared usage, and the same tier
applying throughout the period, 30 days (720 hours) costs $0 and 31 days (744
hours) costs $0.12 before credits and taxes.

The VPC page's one-hour threshold still conflicts with the API. The API resolves
the numeric threshold for the prices observed today, but an account-specific
price response is not a usage record or actual bill. Verify billed usage and
credits in Cloud Billing. No account identifiers or private usage figures are
included in this evidence record.
